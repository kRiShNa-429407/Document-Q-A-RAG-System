# Document Q&A with RAG (LangChain + FAISS + Ollama)

A retrieval-augmented generation (RAG) application that lets you upload your own documents and ask questions about them in natural language. Everything runs locally, so there is no dependency on paid APIs.

## Overview

The app answers questions grounded in the content of user-uploaded **PDF, Word, and text** files. Documents are split into chunks, embedded, and indexed for similarity search. At question time, the most relevant chunks are retrieved and passed to a local LLM to generate the answer.

## Features

- **RAG pipeline built with LangChain** for question answering over your own documents
- **Multi-format support:** upload PDF, Word (.docx), and plain text files
- **Fixed-size chunking** to split documents into consistent segments for embedding
- **FAISS vector store** for fast similarity search over document embeddings
- **Local LLM via Ollama:** responses are generated by an open-source model running on your machine, with no paid API access required
- **Streamlit interface** for uploading documents and chatting with them interactively, with no command-line interaction needed

## How It Works

1. **Upload:** the user uploads one or more documents through the Streamlit UI.
2. **Load and chunk:** files are parsed and split into fixed-size chunks.
3. **Embed and index:** chunks are converted to embeddings and stored in a FAISS index.
4. **Retrieve:** for each question, the most similar chunks are fetched from FAISS.
5. **Generate:** the retrieved context and the question are sent to the Ollama-hosted LLM, which produces the answer.

## Tech Stack

- Python
- LangChain
- FAISS
- Ollama (open-source LLM, run locally)
- Streamlit

## Project Structure

```
.
├── app.py                        # Streamlit front end (upload + Q&A UI)
├── rag_pipeline.py               # Core RAG logic: chunking, embeddings, FAISS, retrieval, LLM call
├── load_rag.py                   # Helper to load/initialize the RAG pipeline
├── table_extractor.py            # Extracts tables from uploaded documents
├── test.py                       # Quick tests / experiments
├── latest_silero_models.yml      # Silero model definitions
├── roadmap.md                    # Planned features and future improvements
├── .env                          # Local configuration (not committed)
└── requirements.txt              # Python dependencies
```

| File | Purpose |
|------|---------|
| `app.py` | Streamlit app: handles multi-format file upload and the interactive Q&A interface. |
| `rag_pipeline.py` | Builds the RAG chain with LangChain: splits documents into fixed-size chunks, embeds them, indexes them in FAISS, retrieves relevant chunks, and queries the Ollama LLM. |
| `load_rag.py` | Loads and sets up the RAG components used by the app. |
| `table_extractor.py` | Pulls tabular content out of documents so it can be included in retrieval. |
| `test.py` | Small script for testing parts of the pipeline. |
| `roadmap.md` | Upcoming features and ideas. |
| `.env` | Environment variables and settings. Keep this out of version control. |

## Getting Started

```bash
# 1. Clone the repository
git clone <your-repo-url>
cd <your-repo-name>

# 2. Install dependencies
pip install -r requirements.txt

# 3. Make sure Ollama is installed and a model is pulled
ollama pull <model-name>

# 4. Create a .env file with your settings (see below)

# 5. Run the app
streamlit run app.py
```

## Configuration

Settings such as the Ollama model name are read from a `.env` file in the project root. Do not commit this file; add it to `.gitignore`.

```
# Example
OLLAMA_MODEL=<model-name>
```

1. Open the Streamlit app in your browser.
2. Upload your PDF, Word, or text documents.
3. Ask questions in the chat box and get answers based on your documents.
